# Social Media Images

Add your social media post images to this folder.

## Required Images:
- instagram-1.jpg
- instagram-2.jpg
- instagram-3.jpg
- instagram-4.jpg

## Image Requirements:
- Format: JPG or PNG
- Size: 600 x 600 pixels (square for Instagram)
- File size: Under 300KB
- Quality: High quality, optimized

## Note:
For automatic Instagram feed integration, consider using:
1. Elfsight (elfsight.com)
2. SnapWidget (snapwidget.com)
3. Taggbox (taggbox.com)

These services allow you to embed your live Instagram feed without coding.
