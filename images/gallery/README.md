# Gallery Images

Add your gallery images to this folder with the following naming convention:

## Required Images:
- performance-1.jpg (Traditional Performance)
- performance-2.jpg (Cultural Festival)
- performance-3.jpg (Stage Performance)
- workshop-1.jpg (Tourist Workshop)
- workshop-2.jpg (Group Workshop)
- event-1.jpg (Wedding Performance)
- event-2.jpg (Hotel Event)
- bts-1.jpg (Rehearsal Session)
- bts-2.jpg (Costume Preparation)

## Image Requirements:
- Format: JPG or PNG
- Recommended size: 1200 x 900 pixels (4:3 aspect ratio)
- File size: Under 500KB for fast loading
- Quality: High quality but optimized

## Tips:
1. Use consistent lighting across photos
2. Include variety: performances, workshops, behind-the-scenes
3. Add photos with tourists for social proof
4. Include close-ups and group shots
